# Security Policy

## Supported Version

Security fixes are applied to the latest commit on the `main` branch while the project remains in active development.

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, pull request, or commit message.

Use GitHub's **Private vulnerability reporting** feature for this repository. Include the affected component, reproduction conditions, impact, and any suggested mitigation. Remove credentials, personal data, real student records, and confidential institutional information from the report.

Maintainers will acknowledge a complete report when available, investigate it, and coordinate remediation and disclosure based on severity. This policy does not promise a specific response time or bounty.

## Safe Research Expectations

- Test only systems and data you own or are expressly authorized to test.
- Do not access, retain, alter, or publish another person's data.
- Avoid service disruption, social engineering, credential attacks, and destructive testing.
- Stop and report promptly if personal or confidential data is encountered.
